## 学习内容

### 基础语法

- print() 输出
- input() 输入
- int() 数据转换
- 变量

### 基本运算

- 加法：+
- 减法：-
- 乘法：*
- 除法：/
- 取余：%

### 条件判断

- if
- elif
- else
- == 判断
- 比较运算
- 嵌套 if

### 逻辑运算

- `and`：多个条件同时成立
- `or`：至少一个条件成立
- `not`：对条件结果取反
- `and` 和 `or` 的组合使用
- 多条件判断

### while 循环

- `while`：条件成立时重复执行
- 循环变量递增：`a = a + 1`
- 循环变量递减：`a = a - 1`
- 累加器：`total = total + a`
- `while + if` 条件判断
- 使用 `%` 判断奇偶数
- 根据用户输入控制循环
- `while + if / elif` 综合使用
- 猜数字小程序
